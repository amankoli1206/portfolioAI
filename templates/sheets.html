Google Cloud Service Account Configuration
Required for authenticating automated write access to Google Sheets
  1. Open the Google Cloud Console and create or select a project.
  2. In APIs & Services > Library, enable both Google Sheets API and Google Drive API.
  3. In IAM & Admin > Service Accounts, click Create Service Account (e.g. portfolioai-sync).
  4. In the Service Account, go to Keys > Add Key > Create new key > Select JSON.
  5. Save the downloaded key file in this project root as: service_account.json
  6. If no SPREADSHEET_ID is configured in .env, PortfolioAI will automatically create a new Google Sheet named PortfolioAI Master Database - [Name] on your first sync.
